# Campusly Student Portal

A responsive, front-end-only student portal made with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser. No build tools or server are required.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `student-portal`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your site URL will appear in the Pages section.

## Customize the demo
- Replace the sample name, student ID, subjects, grades, announcements and schedule in `index.html`.
- Change colors and layout in `style.css`.
- Update interactions in `script.js`.
- Profile edits are saved in the visitor's browser using `localStorage`. They are not sent to a server and will not sync across devices.

## Important
This is a static demonstration portal. It has no authentication, server, or database. Do not publish real student records, grades, IDs, or private information on a public GitHub Pages site.
